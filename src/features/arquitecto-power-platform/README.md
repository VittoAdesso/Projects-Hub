# Arquitectura de soluciones en Power Platform (`arquitecto-power-platform`)

Ruta de aprendizaje interactiva para pasar de construir a diseñar soluciones en Microsoft Power Platform (requisitos, fit/gap, estrategia de entornos y ALM, modelo de datos en Dataverse, seguridad y gobernanza, integraciones y Well-Architected).

## Origen

Migrada desde `/legacy/power-platform-arquitecto-ruta.html` conservando **100 % de paridad** en los 7 módulos, objetivos, temas, recursos oficiales de Microsoft Learn, ejercicios prácticos, preguntas de autoevaluación, filtros por nivel y persistencia del progreso en `localStorage` (`arquitecto-power-platform:progress`).
