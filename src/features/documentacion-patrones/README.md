# Documentación y patrones de diseño (`documentacion-patrones`)

Ruta guiada interactiva para documentar soluciones técnicas (audiencias, convenciones de nombres, registros de decisión ADR, diagramas de arquitectura, patrones de diseño en la nube, patrones de fiabilidad en Power Automate y traspaso operativo) con plantillas copiables de ADR y README.

## Origen

Migrada desde `/legacy/documentacion-patrones-ruta.html` conservando **100 % de paridad** en los 7 módulos, recursos oficiales de Microsoft Learn, preguntas de autoevaluación, plantillas copiables (`#t1` y `#t2`), filtrado por nivel y persistencia del progreso en `localStorage` (`documentacion-patrones:progress`).
